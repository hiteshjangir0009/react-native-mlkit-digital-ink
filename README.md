# @goaid/react-native-mlkit-digital-ink

React Native module for Google ML Kit Digital Ink Recognition with pluggable custom TensorFlow Lite recognizer and native ink-capture Fabric view

## Installation


```sh
npm install @goaid/react-native-mlkit-digital-ink
```


## Usage


```js
import { multiply } from '@goaid/react-native-mlkit-digital-ink';

// ...

const result = multiply(3, 7);
```
